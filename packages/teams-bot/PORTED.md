# Ported code

Parts of this package are ported from Centaur's Teams bot (`services/teamsbot` in
[paradigmxyz/centaur](https://github.com/paradigmxyz/centaur)). Centaur is licensed under
**Apache-2.0 OR MIT**, at the user's option (`LICENSE` at the repository root,
`SPDX-License-Identifier: Apache-2.0 OR MIT`); the ported files are used here under the MIT option.
The MIT licence text and the copyright notice that accompany them are in
[`LICENSE-centaur`](LICENSE-centaur), and each ported file carries an `SPDX-License-Identifier: MIT`
header that points there. Open-Inspect's own licence covers the rest of this package.

- Source: `https://github.com/paradigmxyz/centaur`, path `services/teamsbot/`
- Source commit: `bf32a63504eec5a9d82c09d2a4eb121e1f037796` (`main` at the time of the port)
- Ported on 2026-10-08 for Open-Inspect milestone 2 (the `msteams` bot)

## Files

| Centaur file                     | Here                                                                                        | Adaptation                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| -------------------------------- | ------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `src/types.ts`                   | `src/types.ts`                                                                              | Kept `JsonValue`/`JsonObject`, `TeamsActivity` (with `name` added on `channel`, `team` and `conversation`), `StoredConversationReference`, `FetchFn` (narrowed to the WHATWG `fetch` signature). Dropped the Centaur session transport types (`SessionMessage`, `ExecuteSessionRequest`, ...), the thread-state and render-obligation types and the store interfaces: the OI control plane owns the session, and the SQLite store has its own API.                                                                                                                                                                                                                                                        |
| `src/conversation-reference.ts`  | `src/teams/conversation-reference.ts`                                                       | `toStoredConversationReference` unchanged apart from import paths and formatting; `toBotFrameworkConversationReference` dropped (the REST client addresses conversations from the stored reference itself).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `src/teams-message.ts`           | `src/teams/message.ts`                                                                      | Kept `messageMentionsBot`, mention stripping (`normalizeTeamsText`, which now also collapses whitespace), the quoted-reply extraction (returned as a small `QuotedReplyContext` instead of a `TeamsApiMessage`) and the id getters (`teamsGetChannelId` exported; `teamsGetTeamId` dropped as unused). `isAllowedTeamsActivity` became `checkTeamsActivity`: a single-tenant gate that also requires `type === "message"`, because OI's channel bindings replace Centaur's team/channel allowlists. Added `teamsGetSenderObjectId`, `teamsThreadKey` and `formatQuotedReplyContext`. Dropped `serializeTeamsMessage`, the `raw` payload and the attachment-URL redaction (no attachments in milestone 2). |
| `src/reply-sink.ts`              | `src/teams/reply-sink.ts`                                                                   | The Chat SDK `Thread`/`TeamsAdapter` port is replaced by a two-method `ReplySinkPort` (`post`, `update`) that the Bot Framework REST client provides; `createChatReplySink`/`createAdapterBlockReplySink` are gone, `createBlockReplySink`/`createStreamingEditReplySink`/`updateOrPost` are exported. The placeholder text is `Working...` instead of `Thinking...`. `createStreamingEditReplySink` gained the `initialMessageId` parameter the block sink already had, so it can edit the placeholder posted when the prompt was accepted.                                                                                                                                                              |
| `src/conflate.ts`                | `src/teams/conflate.ts`                                                                     | Unchanged apart from formatting. Driven by `src/sessions/progress.ts` (new, not ported): tool-call callbacks become text deltas, the conflater merges those that arrive during an edit, and the streaming sink writes them under `Working...`.                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `src/logger.ts`, `src/config.ts` | `src/logger.ts`, `src/config.ts`                                                            | Pattern only (structured JSON logger, zod env schema). Rewritten on OI's shared logger with OI's variable names; no Centaur code remains.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `test/conflate.test.ts`          | `src/teams/conflate.test.ts`                                                                | Ported as is (bun:test to vitest); one case added for a failing source.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `test/teamsbot.test.ts`          | `src/teams/message.test.ts`, `src/teams/reply-sink.test.ts`, `src/sessions/handler.test.ts` | The applicable cases are ported against the new API: fails closed for non-Teams activities, tenant allowlist as the outer boundary, personal chats allowed by tenant, quoted thread context sent with the prompt, the conversation reference stored, channel block replies held at the placeholder until completion, personal-chat streaming after a visible placeholder, duplicate activity redelivery ignored. Not ported: the Centaur session-API, render-obligation recovery, lease and attachment cases, which have no counterpart here.                                                                                                                                                             |

Not ported: `src/graph-token.ts` and `src/teams-attachments.ts` (attachments are deferred to a later
milestone), `src/session-api.ts`, `src/session-transport.ts`, `src/state.ts` and `src/teamsbot.ts`
(replaced by `src/control-plane/client.ts`, `src/state/store.ts` and `src/sessions/`).
